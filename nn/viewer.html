linuxtomux NN — model-fit predictor

Predicts whether a (model, quant) from the installer CATALOG fits a device's budget under pick()'s rule. Pure Python stdlib, zero dependencies. Pre-check only: pick() stays the authority, this model never installs anything.

How to use

  • python3 -m nn.train — retrain from the repo data, refreshes this page's numbers.
  • python3 -m nn.score --device android-8gb --all — rank every catalog combo for a device.
  • python3 -m nn.score --device linux-vm-8gb --model Dolphin3.0-Llama3.1-8B --quant Q4_K_M — score one triple.
